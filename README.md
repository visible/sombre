```bash
> what is this?

  a desktop app for coding agents.
  start a session on your mac, keep it going from your phone.

> features?

  ✓ runs claude code and codex on your mac
  ✓ continue any session from your phone's browser
  ✓ approve commands and edits from anywhere
  ✓ one history per session, synced to both screens
  ✓ your code stays on your machine

> status?

  early development. this repo is the landing page for now.

> stack?

  next.js · typescript · tailwind · bun
  gsap + lenis for motion (one clock, see DESIGN.md)

> develop?

  bun install
  bun dev
  bun run verify      lint, types, unit, build

> links?

  https://sombre.ai
  https://sombre.si
```
